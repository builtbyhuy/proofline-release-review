SplashSol — independent free work sample
Observed sources: 30 September 2026; publication dates unknown.

RUN
Open index.html directly in a modern browser. No installation, account, API key or server is needed. All assets are in this folder. Use Load synthetic example, choose the appropriate branch where offered, then Preview local brief. Copy summary uses the browser clipboard; if unavailable on file://, select/copy the readonly output manually. Download JSON creates a local file. Reset clears inputs and output but cannot delete previously downloaded files or erase your system clipboard.

SCOPE
The published careers application links to the project-contact route. Name, phone, email and optional website fields are retained here; branch-specific fields are additions in this prototype.
This is original independent prototype code, not the company's production code, commissioned work, endorsement or a deployed fix. It is an AI-assisted junior work sample, not proof of client results. Synthetic examples use example.com and fictional names. No actual enquiry is sent. Extra fields and validation rules are prototype choices, not assertions about the live form.

DATA AND NETWORK
No external dependencies, assets, APIs, analytics, localStorage or cookies. The content-security policy blocks connect requests and form actions. Input is rendered with textContent or textarea.value, never as HTML. JSON exports preserve messages exactly; no missing company, budget or timeline is invented. Source links are ordinary links opened only on request. Use fictional data during review.

TEST
Run: node tests.cjs
Tests use Node's built-in assertion library. No npm install required. Branch behavior, optional fields, validation, unknown values, long messages, escaped rendering constraints and JSON round trips are checked. Browser review should also confirm keyboard focus, narrow layout and download behavior.
