TRY THE THREE SYNTHETIC CASES
1. Missing quantity: keep it unknown and mark for revision with a note.
   Acceptance is blocked until required fields are complete.
2. Unit error: the fixed prepared draft uses pieces; raw text requests boxes.
   Change the unit, add a note, check the source box, then explicitly accept.
3. Ambiguous date: the source says 12/10 without year/date convention.
   Clear the optional date or mark for revision. Do not infer an ISO date.
   Angle brackets, ampersand and quotes remain literal text.

Prepare JSON or Copy JSON produces the CURRENT full review, including
pending records. Export retains raw source, synthetic reference, original
prepared draft, edited fields, validation messages, notes and decisions.
If clipboard permission is unavailable, the preview is selected for manual
copy. Editing a field clears its record's prior acceptance and source check.
All data is memory-only and is reset on reload; no localStorage is used.

WHAT ACCEPTANCE MEANS
Acceptance records a human action, not proof the fields are correct. The
component checks basic required values but does not understand language or
verify a parts specification. The reviewer owns any decision on ambiguity.
No AI parser is called; each draft is a fixed labelled fixture. There is no
automatic acceptance, external transmission, employment screening, supplier
ranking, technical suitability decision or regulated decision support.
