FACILITY PORTFOLIO LINK REVIEW — INDEPENDENT FREE SAMPLE
Prepared by Huy with AI assistance. Observed 30 September 2026.
Not commissioned, endorsed or reviewed by Facility Design Studio.

OPEN
Double-click index.html in a modern browser. It is a single self-contained
HTML/CSS/JavaScript file and works without an account, build step or internet.
No software installation is required to use the sample.

TRY
1. Start on Published references. Six reference records show zero local flags.
2. Open Exact published observations to compare source text and destinations.
3. Select Synthetic fault practice. Three deliberately injected faults appear:
   an empty demo label, a repeated destination and an unsafe javascript: URL.
4. Return to Published references. The immutable source records remain intact.
5. Download the selected review as a local JSON file if useful.

WHAT THIS IS
A small junior frontend/QA demonstration of repeatable manifest validation.
It checks its own fixture data only. It does not diagnose Facility's website.
Every observed source link had extracted text Visit Website. The longer demo
link labels are written for this sample; full source accessible names, ARIA
attributes and visual context were not inspected.

NETWORK AND DATA
There are no fetch requests, tracking scripts, remote fonts, images, cookies,
storage writes or form submissions. The content security policy blocks network
connections. All six destinations and source URLs are ordinary external links:
only an explicit click opens one in a new tab. Practice mode disables all
destination links. Downloads are local Blob objects released after use.
The sample does not access or scan any client website automatically.

FILES
index.html       Self-contained interface and pure validation logic.
manifest.json    Exact published link observations and separate demo labels.
findings.txt     Source facts, limitations and owner-review guidance.
tests.mjs        Node standard-library tests of data integrity and validation.
browser-test.mjs Optional Playwright local-browser checks; no external pages.
test-results.txt Results and scope of checks actually completed.

TEST
Run from this folder:
  node --test tests.mjs
Optional browser smoke test, if Playwright and its Chromium browser exist:
  node browser-test.mjs
The browser test loads only local index.html and blocks external requests.
No dependencies are required for the standard-library tests.
For an existing Chromium outside Playwright's default cache, set
PLAYWRIGHT_CHROMIUM_PATH to that executable before running the browser test.

SCOPE AND FIT
This is independent, AI-assisted plain HTML/CSS/JavaScript work. It is not
evidence of paid client delivery, professional accessibility auditing,
WordPress/Webflow/GSAP production skill, or authorization to edit a live site.
The public Junior Website Developer listing does not confirm remote terms.

REVIEW BEFORE REUSE
An owner must approve intended destination mappings and label conventions.
Duplicate destinations can be intentional. A passing fixture does not establish
that a site loads, a redirect is correct, or a link has an accessible name.
No correct replacement destinations, lost revenue or measured savings are known.
There is no automatic correction or publishing function.
