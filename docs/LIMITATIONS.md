# Limitations

- All product names, people, requirements, dates, gate counts, and evidence are
  fictional.
- The page is a static interaction sample, not a real import or release system.
- There is no backend, database, account, authentication, authorization, audit
  log, attachment integrity, ticket integration, CI provider integration,
  deployment API, or rollback executor.
- The 10k-row performance artifact is deliberately missing and no performance
  result is claimed.
- The evaluator trusts local JSON input; production evidence would require
  provenance, tamper resistance, access control, and review ownership.
- The browser tests verify selected interaction and layout contracts, not full
  WCAG conformance, cross-browser compatibility, or assistive-technology review.
- GitHub Pages availability does not prove production uptime or support.
